# Skills Suite

Repositório pessoal de skills, regras e ferramentas integradas para agentes Antigravity.

---

## 📦 Conteúdo do Repositório

### 🎮 FiveM Developer Arsenal
* `fivem-developer`: Engenharia e arquitetura para FiveM (QBox, ox_lib, OneSync, fail-closed, anti-exploit).
* `fivem-natives-skill`: Catálogo completo de natives do FiveM via cfxnatives.
* `fivem-performance`: Otimização de resmon (< 0.05ms) e loops adaptativos.
* `fivem-entity-lifecycle`: Gerenciamento do ciclo de vida de peds, veículos e props.
* `fivem-statebags`: Sincronização via OneSync State Bags.
* `fivem-nui-lation`: Padrão de design UI moderno para interfaces NUI.
* `lua`: Padrões de desenvolvimento em Lua 5.4.
* `physics-3d-collision`: Diagnóstico de colisões e colisores 3D (PhysX/Havok).

### 🎯 Planejamento e Decisão (Matt Pocock)
* `grill-me` & `grilling`: Entrevistas e questionamentos interativos antes da codificação para validação de decisões.

### ⚡ RTK (Rust Token Killer)
* Regras e documentação do proxy CLI em Rust para redução de 60-90% de tokens em comandos de terminal.
* Repositório upstream: [rtk-ai/rtk](https://github.com/rtk-ai/rtk)

### 🔍 REA (Reverse Engineering Agent)
* Servidor e definições de ferramentas MCP (`mcp/rea`) para engenharia reversa de binários nativos, código gerenciado, Electron e Web.
* Repositório upstream: [morluto/rea](https://github.com/morluto/rea)
